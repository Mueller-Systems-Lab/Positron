## What Would It Take to Relax a Boundary?

Any boundary relaxation requires:
1. New run card explicitly scoping the boundary change
2. Architecture decision record (ADR)
3. Independent security review
4. Separate Human Gate approval
5. Evidence of safe operation at current boundary level

**No boundary relaxation is proposed or implied by R4.**
