## Database Tables

### runs
| Column | Type | Scoped by | Notes |
|--------|------|-----------|-------|
| id | TEXT PK | — | Generated by crypto.randomUUID() |
| repo_id | TEXT | — | Repository identifier |
| issue_number | INTEGER | — | GitHub issue number |
| branch | TEXT | — | Per-run branch name |
| phase | TEXT | — | Current pipeline phase |
| status | TEXT | — | 'active', 'done', 'failed', 'blocked' |
| autonomy_level | INTEGER | — | 0-4 |
| attempt | INTEGER | — | Fix loop attempt counter |
| started_at | TEXT | — | ISO timestamp |

### run_signals
| Column | Type | FK | Notes |
|--------|------|-----|-------|
| run_id | TEXT | runs.id | Scoped per run |

## Key Recovery Query
```sql
SELECT id FROM runs
WHERE status = 'active'
  AND phase NOT IN ('DONE', 'FAILED_BLOCKED', 'FAILED')
  AND finished_at IS NULL
ORDER BY started_at ASC
```
