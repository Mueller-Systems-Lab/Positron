# Hard-gate bootstrap scope (local governance)

This document preserves the former local bootstrap specification without
inventing a GitHub Issue identity. It is supporting governance for the active
Issue #491 completion run, not the product scope.

The gate entrypoint addresses G10 through G100, admits mutation only on a
non-default branch after preflight, separates visible Playwright readiness
from local work, binds validation to candidate content, and includes happy-path
and negative-control qualification.
