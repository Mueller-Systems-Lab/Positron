# Positron Positioning After #447

Positron is the governance, evidence and control plane around heterogeneous
coding agents.

It is not an editor, foundation model, generic agent framework or duplicate
autonomous controller. Positron owns issue intent, durable execution,
admission, queueing, policy, approval, evidence, verification,
promotion/retry/split decisions and bounded GitHub effects. LLMs, OpenCode,
n8n, browser automation, benchmarks, Proxmox and MCP tools are workers or
external systems behind adapters.

## Evidence-backed differentiators

- controller authority in a durable Run/Job/Attempt model;
- fail-closed policy and human approval boundaries;
- audit-grade versioned contracts and provenance;
- deterministic verification and promotion/retry decisions;
- adapter-neutral workers and measurable model/worker evaluation;
- recovery semantics, idempotency, lease/fencing and stale-result rejection;
- self-hostable operation with fake/dry-run/supervised/real boundaries.

Claims about live n8n, Proxmox, browser or provider operation remain adapter
readiness/evidence claims until the corresponding external integration is
explicitly configured and independently verified.
