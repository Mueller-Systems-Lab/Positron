# Positron v0.2.0

This release is the v0.2.0 stable release prepared from the v0.1.0 stable baseline. The publication and qualification evidence is recorded for Issue #487.

## Operator readiness

`positron.operator-readiness.v1` is backend-backed and exposes actionable blocked states. The readiness surface distinguishes safe demo operation from supervised integration readiness; it does not authorize unsupervised operation.

## Installation onboarding

`positron.install-doctor.v1` supports `--demo`, `--supervised`, and `--json`, with stable reason codes and actionable remediation. Quickstart uses the safe fake/demo path by default.

## Quickstart reliability

The server/worker dependency and workspace build path is shared so a fresh Docker checkout builds the required graph once. Docker build progress is shown in plain mode, and the v0.2 line includes fresh zero-cache first-build proof.

## Runtime reliability

`positron.runtime-budget.v1` provides hierarchical budgets and deadlines, precise termination reasons, separation of provider health from the workload runtime envelope, and late-result fencing.

## Evaluation infrastructure

The landed general infrastructure includes runtime-budget persistence/canaries and the evidence-gated skill-evolution evaluation boundary. `PROGRESSIVE_LOCALIZATION_V1` was evaluated and rejected. No exploration specialization is activated, and no skill specialization or skill productization is activated.

## Safety boundaries

- Fake/demo remains the default for GitHub, SpecKit, and OpenCode.
- Push and merge remain disabled by default; the merge kill switch remains active.
- Unsupervised productive Real Mode remains gated and is not enabled or claimed by this release.
- This release performs no npm publication, container publication, production deployment, or infrastructure deployment.

## Known limitations

Supervised Real Mode validation is evidence-backed, but unsupervised productive Real Mode remains owner-gated. The repository's documented Biome backlog and other current limitations remain unchanged.
