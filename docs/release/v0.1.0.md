# Positron v0.1.0 — Stable Release Notes

This is the controlled publication record for Positron `v0.1.0`. The stable
publication state is established by the matching annotated Git tag `v0.1.0`
and a non-draft, non-prerelease GitHub Release pointing to the same canonical
commit. Before those publication objects exist, this file is the validated
release-preparation record; after they exist, it records the published stable
release.

## Overview

Positron is an evidence-gated GitHub issue-to-PR orchestration system for
supervised autonomous coding workflows. A controller retains authority over
routing, promotion, retries, review, evidence, and completion.

## Core capabilities

- Evidence-gated Specify → Plan → Tasks → implementation → review → verification
  workflow.
- Durable run, job, and attempt state with deterministic transitions and
  resumable control-plane evidence.
- Fake/demo GitHub, SpecKit, OpenCode, and workspace adapters for safe local
  exploration.
- Operator cockpit with dashboard, run detail, evidence, repositories,
  projects, evolution, settings, and administration views.
- Controller-owned mutation authority with persistent locking, fencing, and
  stale-writer rejection.

## Safety defaults

- Fake/demo adapters are the default.
- Push and merge remain disabled by default and protected by existing kill
  switches and approval boundaries.
- Unsupervised productive Real Mode is not enabled or authorized by this
  release.
- This release performs no deployment, production rollout, or package
  publication.

## Compatibility

The qualified CLI contract, API contract, configuration contract, and upgrade
path are PASS. Package version `0.1.0` is consistent across the root and all
workspace manifests.

## Recovery

Migration, online backup/restore, restart recovery, persistent locking,
multi-process locking, fencing, and stale-writer rejection are PASS under the
Issue #465 evidence and final qualification.

## Known limitations

- Unsupervised productive Real Mode remains gated.
- Real GitHub, OpenCode, and SpecKit integrations require explicit credentials,
  binaries, configuration, and supervision.
- The repository-wide Biome lint backlog remains advisory; required release
  gates and changed-surface checks pass.
- Deployment and production operations are outside this repository release.
