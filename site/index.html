03WHY POSITRON

Autonomy needs
a paper trail.

Positron turns autonomous coding from a chat transcript into an inspectable workflow. Each phase leaves artifacts, checks, and a decision record that a person can review.

⌁

Evidence gating

Progress is tied to artifacts and verifiable checks.

◈

Deterministic safety

Push and merge boundaries remain explicit and configurable.

⌘

Supervised autonomy

Workers execute inside a controller-owned state machine.

▦

Auditable execution

Runs, attempts, reviews, and evidence are easy to revisit.

05CURRENT STATUS

Know what is real
right now.

Positron is pre-release and in active development. The status vocabulary below is intentionally conservative.

● Proven

  • Issue-to-PR orchestration surfaces
  • Evidence and run inspection UI
  • Fake/demo adapters and local quickstart
  • Safety and workspace gates

◐ Gated

  • Real GitHub, OpenCode, and SpecKit adapters
  • Push and merge workflows
  • Human-controlled landing decisions
  • Advanced integrations with explicit config

— Deferred

  • Full Real Mode production readiness
  • Provider migration and control-plane redesign
  • Unsupervised production deployment
  • Release publishing
